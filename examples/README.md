# DPP Usage Examples

These examples show how DPP changes the framing and acceptance of real tasks. They are not benchmark results and make no comparative performance claim.

## Software Implementation

```text
Apply DPP v1.3 Operational Edition.

Objective:
Implement CSV export for the existing reporting service.

Binding constraints:
Preserve the current API. Use the repository's existing error model. Do not add dependencies unless necessary. Include tests for quoting, Unicode, empty values, and large rows.

Completion criteria:
The implementation exists in the repository, all relevant tests pass, exported files open correctly in common spreadsheet software, and no placeholder branch remains.

Verification:
Run the full test suite and report the exact commands and results. Inspect generated CSV bytes for the edge cases above.
```

## Research and Analysis

```text
Apply DPP v1.3 Operational Edition.

Objective:
Determine whether the proposed product category has credible current demand.

Binding constraints:
Use current primary sources where available. Separate verified facts, estimates, and inference. Do not invent market-size precision that the evidence cannot support.

Completion criteria:
Provide a defensible conclusion, supporting evidence, major uncertainty, competing interpretation, and the next decision the evidence supports.

Verification:
Every consequential factual claim must be traceable to a cited source. Calculations must show inputs and assumptions.
```

## Document Production

```text
Apply DPP v1.3 Operational Edition.

Objective:
Produce a final client proposal as a PDF.

Binding constraints:
Use the approved pricing and scope exactly. No placeholder text. The document must be readable on mobile and printable on US Letter paper.

Completion criteria:
The PDF exists, contains the complete approved content, has no clipped elements, and includes correct contact and pricing information.

Verification:
Render every page, inspect the visual output, and compare all amounts against the approved source data.
```

## Responsible Use

DPP strengthens production discipline. It does not override law, safety requirements, platform rules, professional obligations, or the need for qualified human review in high-stakes domains.
