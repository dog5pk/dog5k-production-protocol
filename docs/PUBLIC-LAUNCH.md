# Dog5pk Production Protocol v1.4 Is Public

The Dog5pk Production Protocol (DPP) is now publicly available as a platform-independent production standard for human-AI collaboration.

DPP exists for one reason: work should not merely look finished. It should survive inspection, verification, implementation, and reality.

Version 1.4 adds a second layer to the protocol: compliance verification. Following DPP is no longer something an AI can establish merely by saying it followed the rules. Before claiming completion, the work must be checked against the user's objective, constraints, established decisions, material claims, and actual available evidence.

DPP v1.4 distinguishes four completion states:

- Implemented
- Verified
- Verified with limitations
- Blocked

That distinction matters because producing something and proving that it works are not the same thing.

DPP has also completed its first paired benchmark. On Benchmark 001, using Claude under the same task conditions, the Control result scored 35/40 and the DPP-conditioned result scored 37.5/40, a measured improvement of 2.5 points or 7.1% relative to the Control score.

The result is published as it fell, including weaknesses found in both outputs. One benchmark does not prove that DPP improves every model or every task. It does establish one observed case where a highly capable AI produced a measurably stronger result under DPP.

Benchmarks 002 and 003 are intentionally left open for independent participants. Anyone can choose a platform, choose a task, run the same task once without DPP and once with DPP in a fresh conversation, preserve both first completed outputs, score them under the same rubric, and submit the result whether DPP wins, ties, loses, or the test is inconclusive.

The current public materials include:

- DPP v1.4 Reader Edition
- DPP v1.4 Operational Edition
- Quick Start guide
- Whitepaper
- Benchmark 001 results
- Open Benchmark 002/003 framework
- Governance and contribution guidance

DPP is not a jailbreak, model override, or claim that artificial intelligence can be made infallible. It is a production standard designed to make AI-assisted work more dependable, inspectable, honest, and accountable.

Reality is the benchmark. Finished work is the objective. Compliance must survive inspection.
