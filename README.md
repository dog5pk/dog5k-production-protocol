# Dog5pk Production Protocol (DPP)

**Current version:** 1.3  
**Status:** Public Standard  
**Author:** Dog5pk  
**Motto:** *Step Forward or Step Aside.*

The Dog5pk Production Protocol is a platform-independent production standard for human-AI collaboration. It requires work to be correct, complete, inspectable, honest about uncertainty, free of fake progress, and governed by engineering merit rather than convenience.

## Use DPP

- Read the complete standard: [`reader/DPP-v1.3-Reader.md`](reader/DPP-v1.3-Reader.md)
- Copy the operational edition into an AI system: [`operational/DPP-v1.3-Operational.md`](operational/DPP-v1.3-Operational.md)
- Review version changes: [`CHANGELOG.md`](CHANGELOG.md)
- Run and submit reproducible comparisons: [`benchmarks/README.md`](benchmarks/README.md)

## What DPP Rejects

- Placeholders presented as implementations
- Decorative scaffolding
- Known defects left for the user to discover
- Artificially inflated architecture or prose
- Unsupported confidence
- Convenience chosen over demonstrably superior work
- Contracts that falsely imply completed functionality

## Editions

The **Reader Edition** explains and contextualizes the constitutional standard.

The **Operational Edition** contains only the instructions intended to be pasted into ChatGPT, Claude, Gemini, Grok, DeepSeek, Copilot, Cursor, or another AI system.
